# NOVA - Navigational Operations Vehicle Autonomy Club Website

This is the official portfolio website for NOVA (Navigational Operations Vehicle Autonomy Club), founded by Mflash.

Live site: https://mflash777.github.io/nova-website/ 

## About The Project
Started from a bare-bones HTML page and built into a full space-themed portfolio. The site showcases autonomous RC cars, cybersecurity tools, and aerospace projects.

What I built:
- Space theme with dark starry background and glowing blue cards
- Responsive navigation bar (About, Projects, CyberPatriot, Contact)
- Hero section with founder intro and mission
- Horizontal project cards with text left / image right
- Dedicated CyberPatriot toolkit section
- Project updates / dev log

## My Projects Featured

### 1. NOVA Rover
Traxxas Ford Bronco modified with LiDAR, cameras, and a Raspberry Pi 4. Coded in Python for object recognition and autonomous obstacle avoidance.

### 2. CyberPatriot Scripts - My Favorite
Bash toolkit for CyberPatriot competition to harden Windows and Linux VMs. Automates password changes, firewall setup, malware deletion, and service hardening. 
- Helped 80+ teams in our area get started
- Ranked 20th nationwide out of 350+ teams
- Repo: https://github.com/Mflash777/Cyberpatriot-BashCommands

### 3. Stellar Xplorers
Team founded with NJROTC to design a rocket to launch to space and return safely with a data-collecting payload. In partnership with Space Force StellarXplorers competition.
