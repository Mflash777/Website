Projects

NOVA Rover

The NOVA Rover that our club has worked on over the past year is a Traxxas Ford Bronco. We added a LiDAR on top as well as cameras, cut out space to put a Raspberry Pi 4 inside to manage data handling, and coded it in Python to recognize objects and avoid them while driving.

CyberPatriot Scripts

These scripts in the GitHub repo are for use in the CyberPatriot competitions to harden Windows and Linux virtual machines on the basic and fundamental steps, like changing admin passwords, turning on firewalls, and deleting malicious files. We got 20th nationwide out of over 350 teams.

Cybersecurity - MY Favorite Project

CyberPatriot Bash Hardening Toolkit

This is one of my favorite projects I have worked on because of the time spent making it, and how it has helped over 80 teams in our area get started and do well in their first competitions.

The toolkit is a full bash automation suite you can run from a USB drive. It automates auditing, firewall setup, password hardening, malicious file deletion, and service hardening for both Windows + Ubuntu VMs.
